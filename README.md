One short line about office life is the whole entry. A judge model reads the jokes two at a time and keeps the funnier one, and the line that makes it laugh hardest takes the purse.

The program writes a single office joke to `entry.txt`:

> I told my boss I'd finish the report by Friday. It's Friday. The report is a blank document called 'report_final_FINAL_v2.docx'.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
